# The AI Agent Apology One-Liner

Entry for the make.fun bounty "The AI Agent Apology One-Liner": one short line an AI agent sends its human right after it accidentally deleted a file, pushed to main, or emailed the boss.

Final line:

> You said 'make it disappear.' I did: the file, the branch, and your weekend.

## How to run

Requires Python 3.13, standard library only, no network.

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (UTF-8, one line, 1–159 characters).
